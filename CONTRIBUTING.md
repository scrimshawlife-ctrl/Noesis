# Contributing

## The rules that matter here

- **Noesis consumes captures; it does not create them.** An engine that generated its own inputs would be
  scoring itself.
- **Report the method, not a model.** There is no checkpoint to name, and an identity field naming one would
  read as evidence of which model produced the reading.
- **A capture you cannot attribute is not evidence.** Provenance travels with the reading.
