# Noesis

**Noesis** is the Abraxas latent-representation research module. It measures, compares, probes, and experimentally maps machine latent representations against lexical, symbolic, and semiotic representations.

## Mission

Noesis asks a narrow, testable question:

> Which representational structures remain invariant across changes in language, register, symbol system, modality, and model architecture?

It does **not** assume that hidden states are a universal language, a faithful transcript of reasoning, consciousness, intent, or a privileged semantic truth.

## Boundary

- **Hyperlexical**: lexical, slang, register, symbolic-language, and surface-form transformations.
- **Noesis**: embeddings, hidden states, sparse features, latent trajectories, representation alignment, invariance, and experimentally controlled latent communication.
- **Abraxas**: settlement, provenance, governance, SHADOW anomaly detection, and FORECAST evidence-based inference.

Noesis is a sibling of Hyperlexical, not an extension of it.

## First experiment

`EXP-001 Semantic Invariance` tests whether candidate latent features remain stable across controlled lexical, stylistic, symbolic, multilingual, negated, and adversarial paraphrase transformations.
